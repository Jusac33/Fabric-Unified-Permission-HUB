# What We're Focused On

Building the Fabric Unified Permission Hub — a FastAPI web app that provides a unified view of permissions across Microsoft Fabric workspaces and Databricks Unity Catalog. App is running on localhost:8000 with optimized performance (Fabric 25s→1.2s, DBX 12s→385ms). Multi-agent system configured with 14 specialized agents covering app development, debugging, API inspection, security, performance, testing, and Microsoft Fabric analytics workloads.
